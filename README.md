### 🧭 About

- 🏗️  Ten years on **distributed storage & consensus** — spent time inside **etcd / Raft, LevelDB, Pegasus, BaikalDB, Pika, JuiceFS**.
- 🤖  Now going deep on **AI Infra** (LLM inference, routing, sandboxing) and **AI Agents** (MCP, tool use, agent runtimes).
- 🔧  Daily driver: **Go**, with plenty of C++ and Python. I like systems that are small, observable, and hard to break.
- 📍  Beijing · 技术改变生活。
